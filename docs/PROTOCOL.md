# 通信实现与边界

依据工作区 `LSP100_manual_cn.pdf` 附录 A，印刷页 49–53，以及附带 LSP1x LabVIEW 驱动目录。型号、序列号、硬件版本、固件版本通过厂商 Read System Information.vi 所用的 0x0120 起始 28 寄存器独立读取，已实测确认 LSP12-1B / A-01 / 1.0.3.0。

默认 115200 / 8N1，地址 1，两个独立端口。只支持非组模式、通道号 1。地址范围 1–247，不提供广播地址。

| 寄存器 | 用途 |
| --- | --- |
| 0x0001 | 0 停止，1 启动 |
| 0x000D | 1 暂停，2 继续 |
| 0x0060 | 当前方案模式 1–4 |
| 0x0061–64 | 注射器容量及截面积，各带单位 |
| 0x0068–6D | 目标液量、注射流量、抽取流量，各带单位 |
| 0x006E | 驱动力 |
| 0x0074 | 循环次数，0 无限 |
| 0x0100–0x0110 | 故障、运行状态、流量和液量、方向、线速度 |

读取功能码 03，写入功能码 16（十进制，即 0x10）；值与单位作为两个连续寄存器写入。检验帧长、CRC、地址、功能码、异常响应、字节数、写入确认的地址与数量。确认后设置值必须与回读一致。使用功能码 16 而非 06，避免把适配器的原样发送回显误认成写入确认。读取回显会被拒绝，不作透明回显兼容。

各端口独立异步通信、单一信号量串行化事务，1 秒轮询；IO 超时 1 秒。不重试任何写入。停止按钮可在监测事务进行中排队发送；停止不是实时硬件急停。

命令 ACK 早于状态更新。启停及暂停/继续发送后以 100 ms 间隔轮询，最长等待 2.2 秒确认目标状态；未确认时报告错误，不声称已经完成运动。短目标可能在被轮询捕获前完成，此时启动确认可能提示未达到预期状态，应查看最终回读。

设备信息：0x0120–127 型号 ASCII，0x0128–133 序列号，0x0134–137 硬件版本，0x0138–13B 固件版本；每寄存器高字节在前，字符串以 CR 或 NUL 结束。

流量单位 94–106 为 10^(unit-100) µL/min，194–206 为 µL/s，294–306 为 µL/h；显示时换为 mL/min。液量单位 92–106 为 10^(unit-100) µL。面积单位 94–100 为 10^(unit-100) mm²。线速度为两寄存器高字在前的 uint32 × 10^-7 mm/min。

0x010B 在样机返回 1500、800，未充分证实缩放，因此暂不显示百分比。累计液量只转译设备返回，不将它当成传感器测得的实际流量。型号识别使用 0x0120 字符串，不使用未核实的状态高位索引。

参数更改非原子事务：若中途失败，先前写入可能已生效；禁用启动并要求重新读取。停止/暂停/继续回读显示实际状态，并不把写入 ACK 等同于机械运动已经完成。

当前未提供全速、校准、方案增删、组模式、硬件级多泵同步、时间/间隔修改、通信参数写入。0.2.0 提供两条独立串口的软件并行控制。模拟器用于协议与 UI 验证，不模拟设备运动边界。

## 0.2.0 联合控制与显示

`PumpSession` 将前台操作与后台采样分开；采样不改变 Busy 或按钮 Enabled。固定尺寸标签只在内容变化时赋值，布局容器与绘图控件使用双缓冲，采样只进入 CSV，状态变化和操作才进入可见日志。

联合启动/继续先锁定并读取两台，再在一个窗口并排展示参数；窗口打开期间释放串口锁，监测继续。确认后重新读取两台的状态、身份与 30 个当前参数，逐台核对连接代次、端口、地址、型号、序列号和参数。任意一台不满足条件时，向两台都不发送运行指令。检查通过后用两个独立端口并行发送，分别回读状态。

任一路失败或执行过程中取消，都向两台尝试停止，包括可能已经动作但回执丢失的一台。分别记录控制与停止结果，不把“已发送停止”表述成“已确认停止”。前台操作由窗口串行调度，所有联合操作按固定泵顺序取得锁；停止可以取消联合操作并排队取得端口。

确认窗口的注射/抽取时间使用 0x0075/76、0x0077/78，间隔使用 0x0070/71、0x0072/73。按印刷页 53 换算时间单位：97–100 为毫秒到秒，101/102 为 0.1 分钟/分钟，103/104 为 0.1 小时/小时；不能套用统一十进制秒缩放。

## 当前固件的参数写入限制

固件 1.0.3.0 对当前方案单项、成对以及整块参数写入返回异常码 3，尚未解决。参数编辑窗口已明确标注试验功能；日常使用可在泵面板设置，再由本软件读取。不得将模拟测试通过视为设置实机验收通过。

已分析厂商 Set Operation Parameters.vi：aBuild 节点 973 构建 21 字数组，槽位 7 来自常量 FFFF（节点 1238），起始地址 0x0060。按此结构、设备使能前后以及保留时间/参数一致性的整块写入仍被拒绝，故未将未经证实的整块写入替换进交付程序。解析工具 pylabview 仅用于本地分析、不修改厂商 VI，也不随应用安装。
