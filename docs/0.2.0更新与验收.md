# Longer Pump Control 0.2.0

2026-09-14 更新。

## 操作变化

- 仅主界面页头显示 Zhang Lab。窗口标题、安装向导、快捷方式和发行文件仍使用 Longer Pump Control。连接配置和日志沿用 `%LOCALAPPDATA%\LongerPumpControl`。
- 后台采样不再切换按钮禁用状态；静态文字不重复赋值，固定布局配合双缓冲减少闪烁。
- “连接两台”“读取两台参数”“核对参数并启动两台”“暂停两台”“继续两台”“停止全部”集中在窗口顶部。
- 启动和继续在一个窗口并排确认两台实际参数。确认后再次读取并检查，参数或连接有变化时要求重新确认。
- 两张泵卡片分别显示身份、状态、故障、实时流量、累计液量、最近 60 秒趋势，以及运行参数页；底部保留单泵操作。
- 操作日志保留关键事件，完整实时采样仍写入 CSV。
- 驱动助手在启动及 USB 设备变化时检测 FTDI 转接器。Windows 错误 28 才判为缺少驱动；其他设备错误和未插入设备分别提示。非 FTDI 设备不会被误判为适用本驱动。
- 缺驱动时提供应用内离线安装。用户点击并确认后，由 Windows 请求管理员授权；安装前校验驱动 CAT 签名，安装结果保存到日志。应用不会静默提权或自行重装正常驱动。安装前需要断开本应用已连接的泵。

## 保留限制

联合控制是软件并行发送，不承诺硬件级同步。停止仍通过串口发送并回读。

固件 1.0.3.0 的参数写入仍返回 Modbus 异常码 3，参数编辑保留为试验功能。当前应在泵面板修改，再由软件读取并确认。输出使能无需为本次控制功能开启。
