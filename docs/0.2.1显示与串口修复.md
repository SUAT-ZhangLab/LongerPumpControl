# 0.2.1 显示与串口修复

## 显示

窗口首次打开根据当前显示器工作区和 DPI 调整大小；主界面及参数确认、通信设置、参数设置和驱动助手使用同一套缩放逻辑。文字、间距、按钮图标和图表刻度一起缩放。布局始终从原始设计尺寸计算，避免多次切换后尺寸累积误差。

底部“缩放：自动”默认优先按系统 DPI 显示，在屏幕较小时缩小到可用区域。可选择 100%、125%、150%；手动放大后空间不足时提供滚动条。移动到不同 DPI 的显示器或改变显示分辨率时重新计算布局并约束窗口边界。

通过 `.exe.config` 启用 PerMonitorV2，自行管理内容缩放以避免框架重复缩放。运行时已核验原生 PerMonitorV2 上下文。配置依据：[Microsoft Windows Forms 高 DPI 支持](https://learn.microsoft.com/zh-cn/dotnet/desktop/winforms/high-dpi-support-in-windows-forms)。便携版必须保留 EXE 同目录的配置文件；单文件安装包会自动释放此文件。

## 串口

两台泵的端口由主窗口统一分配，不再由各下拉框自动选第一项。首次启动优先分配检测到的 FTDI 串口，其余可用串口按 COM 数字排序。保留仍有效的用户选择，修复重复配置、失效端口和只有一个端口时的重复选择。仅剩一个可用端口时，另一台保持空选。

手动改变一台未连接泵的串口时，如果与另一台未连接泵冲突，会为另一台选择剩余端口。已连接或正在连接的会话始终保留原端口，即便线缆移除也不会悄悄转向其他设备。COM 列表更新不触发会话配置变更或中间状态保存。

FTDI 串口候选不等同于已确认的泵；点击连接后仍读取设备身份并校验 LSP12-1B。自动分配不打开串口、不启动泵。首次识别 USB 串口期间暂缓连接，避免先连接到其他类型的 COM 口。

## 验证范围

新增 15 项布局/串口逻辑检查，覆盖空列表、单端口、首次双端口、重复旧配置、端口迁移、手动交换、大小写和已占用端口保护。GUI 验证原生 DPI 上下文、多种实际窗口尺寸及模拟 96/144/192 DPI 布局、自动/手动缩放切换和下拉框刷新。

本机系统限制最大测试窗口为 2262×1422 外框，因此请求 3000×1800 客户区的测试按实际 2244×1375 客户区验证；没有将该截图当作真实 4K 显示器测试。真实跨显示器移动仍需在对应硬件上体验。

后台采样仍不切换按钮状态、不触发布局刷新。原有 70 项协议、联合控制和驱动检查保留。此次修改不改变泵协议或运动控制。
