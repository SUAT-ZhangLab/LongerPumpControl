# 待解决：固件 1.0.3.0 参数写入被拒绝

## 已确认事实

- 型号 LSP12-1B，硬件 A-01，固件 1.0.3.0。两台泵均可使用 115200/8N1、地址 1 通信。
- FC03 读取 0x0100–110、0x0060–7D、0x0120–13B 正常，CRC 有效。
- FC16 写 0x0001=1/0、0x000D=1/2 可以启动、停止、暂停、继续，实测完成状态回读。
- FC16 写当前方案的模式、目标液量、流量、驱动力等均返回异常码 3，FC06 单值写入亦被拒绝。
- 不是简单的未确认 ACK：错误帧为设备发出的、CRC 有效的 Modbus 异常响应。
- 设备使能 0x0000 可读写，0 与 1 状态下均未解决参数拒绝。测试后恢复为 0。
- 两台泵最终停止、故障码 0；当前运行方案的全部 30 个参数寄存器保留原值。

## 已尝试的合法参数路径

1. 按说明书附录 A 写单值/值与单位对，如驱动力 0x006E、目标液量 0x0068–69、流量 0x006A–6B。
2. 原值写回及较低测试值，均被拒绝。
3. 整块当前参数写回，原值保留。
4. 依据厂商 Set Operation Parameters.vi 中的 21 字数组及槽位 7=FFFF，发送 0x0060 起始参数块。
5. 同时提供一致的低流量、目标液量及时间字段，仍被拒绝。
6. 按说明书通道 1 的 0x2000 偏移访问，可读但参数写入仍被拒绝。
7. 选择已存在方案进入编辑缓冲区后，方案参数写入仍返回异常码 3。

方案编辑选择的附带状态：COM8 0x026E 从初始 1 变为有效方案 2；恢复 1 返回异常码 4。运行方案仍为 2，实际配置未改动。该编辑缓冲区选择不等于切换运行方案。

## 最小复现信息

设备停止、故障码 0 时，发送 FC16，起始寄存器 0x006E，数量 1，值 45（当前值），返回 Modbus 异常码 3。相同连接上写 0x0001=1 可以正常启动，写 0x0001=0 可以正常停止。

需要进一步确认：固件 1.0.3.0 对应的参数写入帧结构、允许的寄存器组合、是否存在额外编辑状态/提交步骤，以及官方上位机在该固件上成功设置参数时的报文示例。目前证据不足以归因于固件缺陷或某个面板开关。
